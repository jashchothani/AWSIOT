AWhat you need

Hardware

Accounts & software

BWire the DHT11 to the ESP8266

If you have the common 3‑pin DHT11 module:

DHT11 VCC ────── NodeMCU 3V3 DHT11 DATA ────── NodeMCU D4 DHT11 GND ────── NodeMCU GND

Bare 4‑pin DHT11 (no module board)? Add a pull‑up resistor (≈10kΩ) between DATA and VCC.

CInstall Arduino IDE

Download and install Arduino IDE from the official site, then open it. Already installed? Skip ahead.

DInstall ESP8266 board support

D1 — Add the boards URL

File → Preferences → paste into "Additional boards manager URLs":
https://arduino.esp8266.com/stable/package_esp8266com_index.json

D2 — Install the package

Tools → Board → Boards Manager → search esp8266 → install esp8266 by ESP8266 Community

ESelect your board & port

Tools → Board → ESP8266 Boards → NodeMCU 1.0 (ESP‑12E Module)
Tools → Port → select your COMx

FInstall libraries

Sketch → Include Library → Manage Libraries — install each:
  • DHT sensor library by Adafruit
  • Adafruit Unified Sensor by Adafruit
  • PubSubClient by Nick O'Leary

GTest the DHT11 before touching AWS

Create a new sketch, save it as AWS_DHT11, paste this, and upload:

#include <DHT.h>
#define DHTPIN D4
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
  Serial.println("\nDHT11 Test");
}

void loop() {
  float temperature = dht.readTemperature();
  float humidity = dht.readHumidity();
  if (isnan(temperature) || isnan(humidity)) {
    Serial.println("DHT11 read failed!");
    delay(2000);
    return;
  }
  Serial.printf("Temperature: %.1f C\n", temperature);
  Serial.printf("Humidity: %.1f %%\n", humidity);
  Serial.println("----------------");
  delay(2000);
}

Open Tools → Serial Monitor at 115200 baud. If readings appear, your hardware works — move on.

I–NSet up AWS IoT Core

I. Open IoT Core

In the AWS Console, search IoT Core and open it. Confirm your region — e.g. Asia Pacific (Mumbai) — ap-south-1.

J. Create the Thing

Manage → All devices → Things → Create thing → Create a single thing

Name it ESP8266-DHT11 (avoid personal info in the name — AWS recommends against PII here).

K. Create the certificate

Choose Auto-generate a new certificate → Next. This X.509 certificate is how AWS authenticates the device.

L. Create an IoT policy

Security → Policies → Create policy — name it ESP8266-DHT11-Policy
{
  "Version": "2012-10-17",
  "Statement": [
    { "Effect": "Allow", "Action": "iot:Connect",   "Resource": "*" },
    { "Effect": "Allow", "Action": "iot:Publish",   "Resource": "*" },
    { "Effect": "Allow", "Action": "iot:Subscribe", "Resource": "*" },
    { "Effect": "Allow", "Action": "iot:Receive",   "Resource": "*" }
  ]
}
Note: This wildcard policy is fine for a first test. For a real device, scope Resource down to that device's specific topics and cert ARN.

M. Attach the policy to the certificate

Security → Certificates → open your cert → Actions → Attach policy → select ESP8266-DHT11-Policy → Attach.

N. Confirm the certificate is ACTIVE

Open the certificate and check its status shows ACTIVE. If not, activate it — it must be active before the device can connect.

O–PDownload & organize certificates

On the certificate creation page, download all three files:

FilePurpose
Device certificate (xxxxx-certificate.pem.crt)Identifies your ESP8266 to AWS
Private key (xxxxx-private.pem.key)Proves the device owns the certificate
AmazonRootCA1.pemLets the ESP8266 verify AWS's server
⚠️ The private key is a secret credential. Never share it, upload it to GitHub, screenshot it, or send it to anyone — including in a support request.

Create a project folder and rename the files, ending with this structure:

AWS_DHT11/ ├── AWS_DHT11.ino └── data/ ├── AmazonRootCA1.pem ├── device.crt └── private.key

Q–VInstall & test the LittleFS uploader

LittleFS stores the certificate files on the ESP8266's flash, separate from your code — so secrets never live inside the sketch.

Q. Check your Arduino IDE version

Help → About Arduino IDE — needs 2.2.1 or newer

R. Install the plugin (Windows)

  1. Close Arduino IDE.
  2. Download the latest .vsix from the official arduino-littlefs-upload releases page.
  3. Create the folder C:\Users\YOUR_USERNAME\.arduinoIDE\plugins if it doesn't exist.
  4. Copy the .vsix file into that plugins folder.
  5. Reopen Arduino IDE.

S. Verify the command is available

Open your sketch, press Ctrl+Shift+P, type Upload LittleFS — you should see Upload LittleFS to Pico/ESP8266/ESP32.

T. Before uploading

Confirm board = NodeMCU 1.0 (ESP‑12E), port is selected, and close the Serial Monitor (the uploader needs the port free).

U. Upload the certificates

With the data/ folder in place, run Ctrl+Shift+P → Upload LittleFS to Pico/ESP8266/ESP32 and wait for success.

V. Confirm the files are on the device

Temporarily upload this test sketch:

#include <LittleFS.h>

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("\nLittleFS Test\n----------------");
  if (!LittleFS.begin()) { Serial.println("LittleFS FAILED!"); return; }
  Serial.println("LittleFS mounted successfully!");
  File root = LittleFS.open("/");
  File file = root.openNextFile();
  while (file) {
    Serial.printf("File: %s | Size: %d\n", file.name(), file.size());
    file = root.openNextFile();
  }
}
void loop() {}
Expect to see all three files listed with nonzero sizes. If so, you're ready for AWS.

WGet your AWS IoT endpoint

AWS IoT Core → Settings → copy the Device data endpoint

It looks like xxxxxxxxxxxxxx-ats.iot.ap-south-1.amazonaws.com. AWS recommends the iot:Data-ATS endpoint type for new connections.

X–ZThe final sketch & upload order

Replace the LittleFS test code with the full program below. Only edit the four values marked YOUR_... — leave the rest as-is.

#include <ESP8266WiFi.h>
#include <LittleFS.h>
#include <WiFiClientSecure.h>
#include <PubSubClient.h>
#include <DHT.h>
#include <time.h>

// ---- WiFi & AWS settings ----
const char* WIFI_SSID     = "YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
const char* AWS_ENDPOINT  = "YOUR-ENDPOINT-ats.iot.ap-south-1.amazonaws.com";
const char* MQTT_TOPIC    = "home/esp8266/dht11";

#define DHTPIN D4
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

WiFiClientSecure secureClient;
PubSubClient mqttClient(secureClient);
BearSSL::X509List*    rootCA     = nullptr;
BearSSL::X509List*    deviceCert = nullptr;
BearSSL::PrivateKey*  privateKey = nullptr;

bool loadCertificates() {
  Serial.println("\nLoading AWS certificates...");
  File rootFile = LittleFS.open("/AmazonRootCA1.pem", "r");
  if (!rootFile) { Serial.println("ERROR: AmazonRootCA1.pem not found!"); return false; }
  rootCA = new BearSSL::X509List(rootFile, rootFile.size());
  rootFile.close();

  File certFile = LittleFS.open("/device.crt", "r");
  if (!certFile) { Serial.println("ERROR: device.crt not found!"); return false; }
  deviceCert = new BearSSL::X509List(certFile, certFile.size());
  certFile.close();

  File keyFile = LittleFS.open("/private.key", "r");
  if (!keyFile) { Serial.println("ERROR: private.key not found!"); return false; }
  privateKey = new BearSSL::PrivateKey(keyFile, keyFile.size());
  keyFile.close();

  Serial.println("AWS certificates loaded successfully!");
  return true;
}

void connectWiFi() {
  Serial.print("\nConnecting to WiFi");
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.printf("\nWiFi connected! IP: %s\n", WiFi.localIP().toString().c_str());
}

void setClock() {
  Serial.println("\nSynchronizing time...");
  configTime(0, 0, "pool.ntp.org", "time.nist.gov");
  time_t now = time(nullptr);
  int attempts = 0;
  while (now < 8 * 3600 * 2 && attempts < 30) { delay(500); Serial.print("."); now = time(nullptr); attempts++; }
  Serial.println(now >= 8 * 3600 * 2 ? "\nTime synchronized!" : "\nWARNING: Time sync failed.");
}

void connectAWS() {
  while (!mqttClient.connected()) {
    Serial.print("\nConnecting to AWS IoT...");
    String clientID = "ESP8266-DHT11-" + String(ESP.getChipId());
    if (mqttClient.connect(clientID.c_str())) {
      Serial.println("CONNECTED!");
    } else {
      Serial.printf("FAILED, MQTT state = %d\n", mqttClient.state());
      delay(5000);
    }
  }
}

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("\n================================\nESP8266 + DHT11 + AWS IoT Core\n================================");
  dht.begin();

  if (!LittleFS.begin()) { Serial.println("ERROR: LittleFS failed!"); return; }
  if (!loadCertificates()) { Serial.println("Certificate loading failed!"); return; }

  connectWiFi();
  setClock();

  secureClient.setTrustAnchors(rootCA);
  secureClient.setClientRSACert(deviceCert, privateKey);
  mqttClient.setServer(AWS_ENDPOINT, 8883);
  connectAWS();
}

void loop() {
  if (!mqttClient.connected()) connectAWS();
  mqttClient.loop();

  float temperature = dht.readTemperature();
  float humidity = dht.readHumidity();
  if (isnan(temperature) || isnan(humidity)) { Serial.println("DHT11 reading failed!"); delay(2000); return; }

  String payload = "{\"device\":\"ESP8266-DHT11\",\"temperature\":" + String(temperature, 1) +
                    ",\"humidity\":" + String(humidity, 1) + "}";

  Serial.printf("\nTemperature: %.1f C | Humidity: %.1f %%\n", temperature, humidity);
  Serial.println("MQTT Payload: " + payload);

  bool success = mqttClient.publish(MQTT_TOPIC, payload.c_str());
  Serial.println(success ? "AWS: Message published!" : "AWS: Publish FAILED!");

  delay(5000);
}

ABSee the data arrive in AWS

Open Tools → Serial Monitor at 115200 — you should see WiFi connect, time sync, then CONNECTED! and messages publishing every 5 seconds.

In AWS IoT Core, open MQTT test client → Subscribe to a topic, enter:

home/esp8266/dht11

Within a few seconds you'll see live JSON like:

{
  "device": "ESP8266-DHT11",
  "temperature": 28.0,
  "humidity": 63.0
}
🎉 Your DHT11 is now sending live data to AWS IoT Core over secure TLS.

What each certificate does

AmazonRootCA1.pem → ESP8266 verifies it's really talking to AWS device.crt → AWS identifies this specific ESP8266 private.key → ESP8266 proves it owns that certificate

ADTroubleshooting

MessageLikely fix
LittleFS failed!Re-check board selection, re-run the LittleFS upload.
AmazonRootCA1.pem not foundFile must be inside data/, not the sketch root — re-upload LittleFS.
device.crt / private.key not foundConfirm exact filenames inside data/.
WiFi won't connectCheck SSID/password, signal range, and that the network is 2.4GHz (ESP8266 can't use 5GHz).
MQTT state = -2Check endpoint, WiFi, certs, and that the clock synced.
MQTT state = 5Usually authorization — confirm cert is ACTIVE, policy is attached, and it allows iot:Connect.
Time matters: TLS certificate validation depends on the ESP8266 having the correct time — that's why configTime() runs before connecting.

AFFull checklist

Work through this in order — don't skip ahead if a step isn't working yet.

  • Install ESP8266 board package
  • Select NodeMCU 1.0 (ESP‑12E)
  • Install DHT, Adafruit Unified Sensor, PubSubClient libraries
  • Test the DHT11 locally
  • Create AWS IoT Thing
  • Create & activate certificate
  • Create IoT policy and attach it to the certificate
  • Download device cert, private key, and AmazonRootCA1.pem
  • Get the AWS IoT Data-ATS endpoint
  • Install the LittleFS uploader plugin
  • Put the 3 certificate files in data/ and upload via LittleFS
  • Confirm files exist on the device
  • Fill in WiFi + AWS endpoint in the sketch, upload it
  • Open Serial Monitor, confirm "CONNECTED!"
  • Subscribe to home/esp8266/dht11 in the MQTT test client and see live JSON
